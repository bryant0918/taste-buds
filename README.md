# Taste Buds

Pulls nearby restaurant data from multiple providers (Google Places, Yelp, Foursquare, OpenStreetMap/Overpass), dedupes, and filters out places already visited. Used to pick where to go for Friday lunch.

## Setup

```
pip install -r requirements.txt
cp .env.example .env  # fill in your API keys
```

## Usage

```
python combined.py
```
